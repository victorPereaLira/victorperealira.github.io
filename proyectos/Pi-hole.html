Pi-hole

Pi-hole es un bloqueador de anuncios a nivel de red que funciona como servidor DNS local. Permite filtrar solicitudes no deseadas antes de que lleguen a los dispositivos, mejorando la velocidad y la privacidad en toda la red doméstica.

✨ Características

  • 🚫 Bloqueo de anuncios en toda la red
  • 📊 Monitorización DNS en tiempo real
  • ⚡ Mejora del rendimiento
  • 🔒 Bloqueo de rastreadores

💻 Tecnologías

  • Raspberry Pi
  • Pi-hole
  • Raspberry Pi OS Lite
  • SSH
  • DNS

🛠️ Proceso de implementación

Este proyecto surgió por la necesidad de eliminar los anuncios y mejorar la experiencia de navegación. Aprovechando una Raspberry Pi, se implementó una solución capaz de bloquear publicidad a nivel de red.
