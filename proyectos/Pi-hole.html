Pi Hole

Pi-hole es un proyecto que consiste en la instalación de un bloqueador de anuncios a nivel de red utilizando un Raspberry Pi. con el objetivo de bloquear publicidad y rastreadores en toda la red domestica. Pi-hole actua como un servidor DNS local, filtrando solicitudes no deseadas y mejorando la velocidad y seguridad de la navegación. El proyecto explica la configuracion y las listas de bloqueo personalizadas, y la integracion con dispositivos de la red.

✨ Características principales

  • 🚫 Bloqueo de anuncios a nivel de red.
  • 📊 Monitorización del tráfico DNS en tiempo real.
  • ⚡ Mejora del rendimiento de navegación.
  • 🔒 Mayor privacidad al bloquear rastreadores.

💻 Tecnologías utilizadas

  • Raspberry Pi
  • Pi-hole
  • Raspberry Pi OS Lite
  • SSH
  • DNS

🛠️ Proceso de implementación

Este proyecto surgió porque siempre me ha molestado tener que cerrar pop-ups mientras navego por internet. No solo interrumpen la experiencia, sino que también hacen que todo funcione más lento.

Como ya tenía una Raspberry Pi en casa, decidí aprovecharla para bloquear los anuncios antes de que llegaran a mis dispositivos. Tras investigar diferentes opciones, elegí Pi-hole por su gran comunidad y facilidad de uso.

⚙️ Instalación

Para comenzar, instalé Raspberry Pi OS Lite (32-bit) utilizando Raspberry Pi Imager, ya que es una opción ligera y sin interfaz gráfica.

Una vez instalado el sistema, me conecté por SSH para actualizarlo y preparar el entorno. 

sudo apt install curl
curl -sSL https://install.pi-hole.net | bash

Durante la instalación, el asistente me permitió configurar:

  • Interfaz de red (eth0)
  • IP estática
  • Proveedor DNS
  • Listas de bloqueo

Al finalizar, Pi-hole proporciona un panel web desde el que se puede monitorizar el tráfico y gestionar el sistema de bloqueo.

📊 Resultados

Tras implementar Pi-hole en la red, se observaron mejoras significativas tanto en rendimiento como en privacidad:

  • 🚫 Reducción notable de anuncios en todos los dispositivos.
  • ⚡ Navegación más rápida al evitar cargas innecesarias.
  • 🔒 Bloqueo de dominios asociados a rastreadores.
  • 📊 Monitorización en tiempo real del tráfico DNS.

Además, el sistema permite visualizar estadísticas como el número de consultas bloqueadas, los dominios más solicitados y el porcentaje de bloqueo total.

Este proyecto demuestra cómo una solución sencilla puede mejorar significativamente la experiencia de usuario en toda una red doméstica.
