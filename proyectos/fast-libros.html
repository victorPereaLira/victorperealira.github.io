Fast Libros

Este proyecto consiste en el desarrollo de una aplicación web llamada Fast Libros, diseñada para gestionar bibliotecas personales de forma ágil y eficiente. Permite registrar, buscar y organizar libros con una interfaz sencilla y accesible desde cualquier navegador.

✨ Características principales

  • 📚 Registro y gestión completa de libros.
  • 🔎 Búsqueda rápida por título, autor o categoría.
  • 🗄️ Base de datos integrada para almacenamiento seguro.
  • 🌍 Acceso desde cualquier dispositivo con navegador web.
  • 📖 Organización por categorías y géneros.
  • ⭐ Sistema de valoración de libros.
  • 📊 Estadísticas de lectura.
  • 📱 Diseño responsive adaptable a móviles.

💻 Tecnologías utilizadas

  • Python – Lenguaje de programación principal
  • Flask – Framework web
  • SQLite / PostgreSQL – Base de datos
  • HTML5 & CSS3 – Interfaz de usuario
  • JavaScript – Interactividad
  • Jinja2 – Motor de plantillas
  • Bootstrap – Estilos responsive
  • Git & GitHub – Control de versiones

Instalación

La instalación de Fast Libros es muy sencilla. Solo necesitas tener Python instalado en tu sistema y seguir estos pasos para poner en marcha la aplicación.

La versión actual es Fast Libros v1.0.0.

Proceso de instalación

Para instalar y ejecutar Fast Libros localmente, sigue estos pasos:

1. Clonar el repositorio

git clone https://github.com/victorPereaLira/FastLibro.git

Clonamos el repositorio desde GitHub a nuestro equipo local.

2. Crear entorno virtual

python -m venv venv

Creamos un entorno virtual para aislar las dependencias del proyecto.

3. Activar entorno virtual

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate

Activamos el entorno virtual según nuestro sistema operativo.

4. Instalar dependencias

pip install -r requirements.txt

Instalamos todas las dependencias necesarias para el proyecto.

5. Ejecutar la aplicación

python app.py

Iniciamos el servidor y accedemos a http://localhost:5000 en el navegador.

🔧 Funcionalidades implementadas

Fast Libros ofrece las siguientes funcionalidades para la gestión de bibliotecas:

  • CRUD completo de libros (Crear, Leer, Actualizar, Eliminar).
  • Sistema de búsqueda por título, autor o categoría.
  • Filtros por género, año o valoración.
  • Base de datos para almacenar toda la información.
  • Interfaz responsive que se adapta a móviles y tablets.
  • Exportación de datos a CSV y PDF.
  • Estadísticas de lectura y gráficos.

🎨 Diseño y experiencia de usuario

La interfaz de Fast Libros ha sido diseñada pensando en la simplicidad y facilidad de uso. Utiliza colores suaves y una disposición clara de los elementos para que la gestión de libros sea una tarea agradable.
