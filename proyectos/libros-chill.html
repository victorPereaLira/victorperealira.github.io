Libros & Chill

Libros & Chill es una aplicación Android desarrollada para organizar tu biblioteca personal de forma sencilla y visual. Permite gestionar libros, añadir opiniones y llevar un registro de tus lecturas.

✨ Características principales

  • 📚 Gestión completa de libros.
  • 📝 Comentarios y valoraciones de usuarios.
  • 🔎 Búsqueda por título o autor.
  • ☁️ Sincronización en la nube con Firebase.
  • 🎨 UI basada en Material Design.
  • ❤️ Lista de libros favoritos.
  • ✅ Marcador de libros leídos/pendientes.
  • 📱 Diseño adaptado a dispositivos móviles.

💻 Tecnologías utilizadas

  • Kotlin – Lenguaje de programación principal
  • Firebase Authentication – Autenticación de usuarios
  • Firebase Firestore – Base de datos en tiempo real
  • Material Design – Diseño de interfaz
  • Google Books API – Información de libros
  • Git & GitHub – Control de versiones

🧠 Desarrollo del proyecto

📱 Sobre la aplicación

Libros & Chill fue desarrollado en Kotlin con el objetivo de ofrecer una solución intuitiva para lectores que desean gestionar su biblioteca personal de manera eficiente.

☁️ Backend y almacenamiento

Se utilizó Firebase Authentication para la gestión de usuarios y Firestore como base de datos en tiempo real para almacenar la información de libros, favoritos y estado de lectura.

📖 Integración con API

La aplicación se integra con la Google Books API para obtener información actualizada de los libros (portada, sinopsis, autor, etc.) de forma automática.

🎨 Diseño

El diseño sigue los principios de Material Design de Google, garantizando una experiencia visual moderna, intuitiva y consistente en todos los dispositivos Android.
