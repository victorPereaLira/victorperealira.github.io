Libros & Chill

Libros & Chill es una aplicación Android desarrollada para organizar tu biblioteca personal de forma sencilla y visual. Permite gestionar libros, añadir opiniones y llevar un registro de tus lecturas.

✨ Características

  • 📚 Gestión de libros (favoritos, leídos y pendientes)
  • 📝 Comentarios de usuarios
  • 🔎 Búsqueda por título o autor
  • ☁️ Sincronización en la nube
  • 🎨 UI basada en Material Design

💻 Tecnologías

  • Kotlin (Android)
  • Firebase (Auth + DB)
  • Material Design
  • Google Books API

🧠 Desarrollo del proyecto

Libros & Chill es una aplicación Android desarrollada en Kotlin con el objetivo de facilitar la gestión de una biblioteca personal de libros. El proyecto se centra en la organización, consulta y seguimiento de lecturas de forma sencilla y visual.

Durante su desarrollo se utilizó Firebase como backend para la autenticación y almacenamiento de datos, junto con la Google Books API para obtener información actualizada de los libros. La interfaz fue diseñada siguiendo principios de Material Design para ofrecer una experiencia de usuario limpia e intuitiva.

La aplicación está estructurada en diferentes pantallas que permiten al usuario buscar libros, guardarlos en listas personalizadas y consultar su información detallada.
