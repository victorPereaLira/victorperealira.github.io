Libros & Chill

Libros & Chill es una aplicación Android desarrollada para organizar tu biblioteca personal de forma sencilla y visual. Permite gestionar libros, añadir opiniones y llevar un registro de tus lecturas.

✨ Características

  • 📚 Gestión de libros
  • 📝 Comentarios de usuarios
  • 🔎 Búsqueda por título o autor
  • ☁️ Sincronización en la nube
  • 🎨 UI basada en Material Design

💻 Tecnologías

  • Kotlin
  • Firebase
  • Material Design
  • Google Books API

🧠 Desarrollo del proyecto

Libros & Chill fue desarrollado en Kotlin con el objetivo de ofrecer una solución intuitiva para lectores que desean gestionar su biblioteca personal.

Se utilizó Firebase para autenticación y almacenamiento, junto con Google Books API para obtener información real de libros.

La aplicación fue diseñada siguiendo Material Design para garantizar una experiencia visual moderna y cómoda.

📸 Pantallas del proyecto

Login inicial

Acceso con inicio de sesión, registro y selector de idioma.

Registro

Creación de cuenta integrada con Firebase Authentication.

Inicio usuario

Recomendaciones personalizadas y navegación principal.

Detalle del libro

Sinopsis, autor, portada y opción de compra.

Búsqueda

Consulta libros por título o autor usando la API.

Favoritos

Listado personal de libros favoritos filtrables.

Leídos

Historial de libros completados por el usuario.

Pendientes

Libros guardados para futuras lecturas.
